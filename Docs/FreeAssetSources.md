# Free asset sources

Moved to Confluence: [Free Asset Sources](https://viktoravoitovych.atlassian.net/wiki/spaces/HE/pages/7929865/Free+Asset+Sources)
(HedgehogEngine space, under Engine Architecture & Subsystems).

It lists free sources of models, PBR textures, HDRIs, characters and animation, sound and music,
fonts, UI and 2D assets and sample scenes, each with its licence and how its formats fit the ones
the engine reads (`Docs/Assets.md` section 2), and how to record a shipped asset in
`THIRD_PARTY_NOTICES.md`. Keep it there; this file only points to it.
